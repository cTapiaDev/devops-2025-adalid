## 🎯 **Competencia del Plan Formativo**

Al finalizar este curso, serás capaz de **implementar la transición de una organización hacia las prácticas DevOps** con el objeto de producir productos y servicios de software con mayor rapidez, calidad y a un menor costo, acorde a las buenas prácticas de la industria.

---

## 📚 **Módulos del Curso**

Nuestro viaje a través de DevOps se divide en los siguientes módulos clave. La duración total del curso es de **177 horas**.

| Módulo | Nombre del Módulo | Duración | Descripción |
| :---: | :--- | :---: | :--- |
| 🎓 **1** | **Orientación al Perfil y Metodología** | 9 hrs | Analizar las competencias del plan formativo, su relación con el perfil laboral y la metodología del curso. |
| 🌱 **2** | **Fundamentos y Adopción DevOps** | 15 hrs | Distinguir los principios fundamentales de las prácticas DevOps y su rol en un entorno ágil. |
| 🔄 **3** | **Integración Continua (CI)** | 33 hrs | Implementar un proceso de `build` automatizado utilizando herramientas de control de versiones y gestores de construcción. |
| 🧪 **4** | **Automatización de Pruebas** | 24 hrs | Implementar técnicas de automatización de pruebas en el ciclo de CI para asegurar la calidad del producto. |
| 🏛️ **5** | **Arquitectura y Escalabilidad** | 24 hrs | Utilizar tecnologías de contenedores y orquestación para facilitar la operación y el escalamiento. |
| ☁️ **6** | **Tecnología Cloud y DevOps** | 27 hrs | Aplicar conceptos de arquitectura cloud y habilitar infraestructura como código (IaC). |
| 📈 **7** | **Despliegue y Monitoreo Continuo** | 24 hrs | Implementar mecanismos de despliegue y monitoreo continuo para la gestión de eventos y logs. |
| 💼 **8** | **Desarrollo de Portafolio** | 12 hrs | Crear un portafolio de productos utilizando herramientas tecnológicas para potenciar el perfil profesional. |
| 👔 **9** | **Empleabilidad en la Industria Digital** | 9 hrs | Elaborar un plan de búsqueda laboral y aplicar técnicas para la preparación de entrevistas. |
